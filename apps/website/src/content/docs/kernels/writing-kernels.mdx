---
title: Writing Kernels
description: Write the WGSL function that Volten will run as a compute kernel.
---

A callable kernel contains the WGSL code that runs on the GPU and creates a
logical node when invoked with bindings.

```ts
import { kernel } from '@volten/core';

const scale = kernel({
    shader: `
  fn main(gid: vec3u) {
    output[gid.x] = input[gid.x] * multiplier;
  }
`
});
```

You write a `main` function. Volten adds the compute entry point, workgroup size, bindings, and safety guard around it.

## Builtin Shorthands

Volten expands a few parameter names in `main`:

| Name   | Type                   | Meaning                |
| ------ | ---------------------- | ---------------------- |
| `gid`  | `vec3u` or `vec3<u32>` | Global invocation id   |
| `lid`  | `u32`                  | Local invocation index |
| `lid3` | `vec3u` or `vec3<u32>` | Local invocation id    |
| `wid`  | `vec3u` or `vec3<u32>` | Workgroup id           |
| `nwg`  | `vec3u` or `vec3<u32>` | Number of workgroups   |

```ts
const writeLocalIds = kernel({
    shader: `
  fn main(gid: vec3u, lid: u32) {
    data[gid.x] = f32(lid);
  }
`
});
```

You can also write the full WGSL builtin syntax yourself.

```wgsl
fn main(@builtin(global_invocation_id) gid: vec3u) {
  data[gid.x] = data[gid.x] * 2.0;
}
```

## Helper Functions

Only the function named `main` is treated as the kernel entry point. Other functions are left alone.

```ts
const squareValues = kernel({
    shader: `
  fn square(x: f32) -> f32 {
    return x * x;
  }

  fn main(gid: vec3u) {
    data[gid.x] = square(data[gid.x]);
  }
`
});
```

## Context-Dependent Shaders

Pass a function as `shader` when the WGSL should depend on the active GPU. The
function receives the device and its enabled features and limits, and returns
the WGSL source to use.

```ts
const processValues = kernel({
    shader: ({ device, features, limits }) => {
        if (features.has('shader-f16')) {
            return shaderUsingF16;
        }

        if (limits.maxComputeWorkgroupStorageSize >= 32768) {
            return shaderUsingMoreWorkgroupStorage;
        }

        return portableShader;
    },
    threads: 'input'
});
```

The selector runs when a node is first materialized by a run, wait, or read
operation, not when `kernel()` is called. It is synchronous, must return a WGSL
string, and is resolved once for that materialized node.

## Labels

Add a label when you want clearer debug output and browser GPU tooling names.

```ts
const scaleValues = kernel({
    shader: `...`,
    label: 'scale values'
});
```

:::note[WebGPU mapping]
Volten injects `@compute @workgroup_size(...)` for the final shader. You do not write those attributes unless you opt into lower-level control later.
:::

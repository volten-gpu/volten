# Security Policy

## Supported Versions

Volten is pre-1.0. Security fixes are provided for the latest released version.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older   | No        |

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's vulnerability
reporting flow on the repository Security tab.

Do not open a public issue for suspected vulnerabilities. Include enough detail
to reproduce or assess the issue, such as affected versions, environment,
example code, and any known workarounds.

Reports will be acknowledged as soon as possible. Confirmed vulnerabilities will
be fixed in a release and documented in the release notes when appropriate.
